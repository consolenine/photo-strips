# Photo Strips

Make photobooth-style strips (1–4 strips × 4 photos) on an A4 landscape sheet, with basic photo edits,
"people in colour / background in B&W", print tuning for inkjet paper and dotted cutting lines.
Export as a 300 ppi PDF or JPEG, or print directly.

Everything runs in the browser — photos are never uploaded anywhere.

Live site: https://consolenine.github.io/photo-strips/
